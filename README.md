# 금융 뉴스 비동기 데이터 파이프라인 및 LLM 시스템

본 프로젝트는 실시간 금융 뉴스 데이터를 수집하고 비동기 파이프라인을 통해 LLM 분석을 수행하는 시스템입니다.

* **FastAPI 기반 비동기 API 서버 설계 및 구현**
* **비동기 웹 크롤러(Asyncio/Aiohttp) 파이프라인 구축**: 대량 뉴스 수집 속도 최적화
* **OpenAI API 연동 및 감성 분석 프롬프트 엔지니어링**: 실시간 뉴스 분석 자동화

### Tech Stack
* Python, FastAPI, Asyncio, OpenAI API, BeautifulSoup
